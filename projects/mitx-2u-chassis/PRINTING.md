# Printing mitx-2u-chassis

| Setting | Recommendation |
|---|---|
| Material | PETG |
| Printer | Bambu P1S |
| Nozzle | 0.4 mm |
| Layer height | 0.2 mm |
| Walls / perimeters | 3 minimum |
| Infill | 20% gyroid |
| Print speed | 50 mm/s |
| Supports | None — support-free by construction (see below) |
| Orientation | Flat, front face down (panel thickness = build height) |

Notes: this task only builds the front faceplate + board standoffs (walls,
floor, and the rear `#40` mate follow in Tasks 2-3, with their own
orientation/support notes then). The faceplate's ear holes, IO-shield
cutout, PCIe slot aperture, and power button hole are all straight vertical
prisms through the panel's short (thickness) axis — no overhangs. The board
standoffs are plain cylindrical posts (pilot bore subtracted) printing
straight up, also no overhangs.
